The code included in this repository was used to support the paper submitted for the proceedings of the XAFS 2026 conference.

The three notebooks included are intended to show:

How to add provenance a Galaxy RO-Crate
How to extract interoperability and discovery metadata from the RO-Crate (using the CDIF-4-XAS model)
How to use the interoperability metadata to extract and use the data in the RO-Crate outside Galaxy
